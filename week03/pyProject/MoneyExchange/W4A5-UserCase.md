# Money Exchange System

## User Case Diagram



![Image](https://github.com/Richard-Xiahou/MSE800/blob/main/week03/images/W4A5%20-%20Money%20Exchange.drawio.png)

The Money Exchange System has one main actor, the Cashier.

The cashier can manage customers, view exchange rates, update exchange rates, exchange currency, and view transaction records.

The Exchange Currency use case includes searching the customer, calculating the exchange amount, and saving the transaction into the database.

Printing a receipt is optional after the transaction is completed.
