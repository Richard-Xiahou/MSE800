# Matrix Multiplication System

## Introduction

This project is a simple Matrix Multiplication System developed using Python.

The project is designed to practice Object-Oriented Programming (OOP).

The system can create matrices, modify matrix values, print matrices and perform matrix multiplication.

---


## Matrix Class

The Matrix class stores matrix information.

### Attributes

- rows
- cols
- data

### Methods

- __init__()
- print_matrix()
- display_info()
- set_value()
- get_value()
- set_matrix()
- fill()
- input_matrix()
- multiply()

---

## Features

The program supports the following functions.

1. Create an empty matrix

2. Run the default matrix multiplication example

3. Fill the whole matrix with one value

4. Input a matrix manually

5. Print matrix information

6. Multiply two matrices

---

## Matrix Multiplication

The system checks whether two matrices can be multiplied.

The number of columns of Matrix A must be equal to the number of rows of Matrix B.

If the matrix sizes do not match, the program raises an error.
