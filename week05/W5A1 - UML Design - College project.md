# College Management System UML Design

## Introduction

This project is a simple College Management System.

The project focuses on three main areas:

- Students
- Lecturers
- Courses

The purpose of this project is to practice UML diagrams learned in Week 4 and Week 5.

---

## Project Scope

This project includes only three entities:

- Student
- Lecturer
- Course

The project does not include login, payment, timetable or other advanced functions.
